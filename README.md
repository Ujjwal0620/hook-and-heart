# Hook & Heart

A romantic greeting-card experience designed for Vercel static deployment.

## Included
- Full-screen romantic card UI
- Responsive mobile/desktop design
- Google Fonts (Outfit + DM Serif Display)
- Animated ambient hearts
- Letter reveal and smooth scrolling
- Explicit, browser-controlled camera permission flow
- Local camera preview only; no hidden capture or upload
- Creator dashboard explaining the consent-safe architecture

## Vercel
Import this repository into Vercel and use the default settings. No build command or environment variables are required.

## Privacy
Camera access is requested only after the visitor chooses the camera button and the browser permission prompt is shown. This project does not secretly record, upload, or stream camera footage.
